02 / The arithmetic

Stop translating
the same equation.

The encrypted computation works modulo four BFV primes. The earlier proof system expressed that arithmetic inside BabyBear, a different field, using carry and range machinery. The new backend proves directly over each BFV field.

The same small arithmetic relation covers the complete update and the eleven-stage linear dot computation, including rotations and key switching. It constrains every row, including the last. The commitments and transcript use domain-separated SHA-256.

The first full trial reused the inputs from a real expiry in the continuing learner, then made fresh proofs. Both resulting ciphertexts matched the original captured bytes. The consumer independently accepted all 384 proofs.

Faster arithmetic is useful.
The comparison still has a shape.

The compact predecessor’s first complete two-class squared query took 1,103.216 seconds and generated 232 proofs totaling 235,624,423 bytes. The successor’s first two-class linear query took 113.070 seconds. It changes both the score and the proof profile. These are observations of different systems, not a security-equivalent speedup ratio. Inspect both recorded queries.

Checking is still expensive.

For the new one-class trial, native public FHE computation took 0.370 seconds. Independent proof consumption took 14.20 seconds, dominated by rebuilding public preprocessing commitments. This small model does not establish an outsourcing efficiency win.

What changed in the proof, and what is still assumed

The experimental profile uses 8× low-degree extension, 64 FRI queries, quartic challenges and no proof of work. It has no derived numerical security level. Its new Rust AIR and field integration are not the predecessor’s generated Lean descriptor or a new end-to-end formal theorem.

The public coefficient rows, canonical parsers and transforms, patched Plonky3 verifier, SHA-256 binding, Fiat–Shamir model and application controller remain assumptions or proof obligations. The polynomial commitment is nonhiding; its operands are already public ciphertexts, evaluation-key coefficients or deterministic public transforms. Construction and profile.

Next / A completed change in layout

Eight classes
share the work.

Then we changed what an encrypted bank holds. One fixed lane now carries the sum of a class’s up to eight recent encrypted examples; eight classes share one bank. Inference returns exact sum / count scores. A teaching still subtracts the exact expired contribution before adding the new example.

On a separate nine-class authored workload, the complete run finished all 22 operations: eighteen teachings, three queries and an actual restart, exercising two FIFO expirations. It produced and independently consumed 2,336 fresh proofs, totaling 424,195,924 bytes, in 499.706 seconds of recorded worker-attempt wall time.

The first query answered eight classes from one bank: 352 proofs, 64,340,276 bytes, 87.672 seconds. Adding the ninth class needed a second bank: 704 proofs, 128,680,095 bytes, 162.888 seconds. A fresh query after restart took 120.437 seconds and returned the same class sums and ranking. Across the three queries, all forty bank lanes—including padding—matched the reference.

The separate nine-item plaintext check went from 8/9 to 9/9 after the previously untaught ninth class was introduced. That change does not establish a general learning gain. This is a different corpus from the two-class explorer above; these timings do not supply a comparison on the same corpus at an equal security level. The substantive change is that one proved bank computation now answers up to eight classes.

04 / The unfinished property

The machine continues.
The full reader survives.

The service checks before it reads. The key can still read without that service.

The local instance retains the full BFV secret key. A successful proof-gated query does not remove that credential or turn it into a restricted reader.

The E5 text encoder also runs in plaintext at the trusted issuer. The assembled application does not claim privacy against its operator, the absence of a master reader, or whole-system post-quantum security.
